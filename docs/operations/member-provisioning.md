# CCOR IDX Staff Provisioning Runbook

Use the Admin Portal **Guided Provisioning** action. Each successful step writes canonical account data and can be resumed from Account Detail.

1. Confirm the account name, member email, CCOR/member ID, and applicable agent/office MLS identity.
2. Select the plan and record `manual` or `growthzone` entitlement source plus the external reference.
3. Choose agent, office, or market scope. Validate the MLS ID against current D1 inventory.
4. Create the Member Portal owner invitation. A request is not proof of real email delivery.
5. Add the exact website hostname. It begins disabled/unverified. Complete Cloudflare/DNS work before authorizing it.
6. Complete display name, brokerage, contact email/phone, logo, and supported colors.
7. Enable the search widget and copy the complete responsive embed snippet.
8. Resolve every Account Detail readiness blocker. Record the required existing launch-check evidence and perform the manual visual/install checks.

Use the explicit lifecycle modal for suspend, cancel, reactivate, site disable, or domain removal. These actions preserve configuration and buyer/member data. Never delete D1 records as a routine support action.

If provisioning stops midway, reopen the account; Setup Progress shows the next incomplete canonical area. Do not create a duplicate account to resume work.
